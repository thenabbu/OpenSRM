# Testing class reminders on an iPhone (one friend session is enough)

You do **not** need to understand anything technical. Do these steps once and
report what you see. Estimated time: 5 minutes + a class period of waiting.

## Before you start

- iPhone or iPad on **iOS 16.4 or newer** (Settings → General → About →
  Software Version).
- OpenSRM already logged in on the phone's browser (ask for the link).

## Step 1 — install the app to your Home Screen

1. Open the OpenSRM page in **Safari**.
2. Tap the **Share** button (square with an arrow).
3. Scroll and tap **Add to Home Screen** → **Add**.
4. A small OpenSRM icon appears on your Home Screen.

> Reminders only work from this installed app — a normal Safari tab cannot
> receive them. This is an iOS rule, not an app bug.

## Step 2 — open and enable reminders

1. Tap the **new OpenSRM icon** (not Safari — the icon on the Home Screen).
2. Go to the **Timetable** tab.
3. Scroll below "Edit history" to the **Class reminders** card.
4. Tap **Enable reminders** → accept the notification permission prompt.
5. The card should say **"Reminders on · 10 minutes before each class."**
6. Tap **Send test notification**.

## Step 3 — confirm it arrives

1. Wait ~10 seconds — the notification should pop up.
2. **Lock the phone** (press the side button) and send another test — the
   screen should wake with it.
3. Note the exact time it appeared.

If the card says permission is blocked (you tapped "Don't allow" earlier):
iOS will never re-ask. Fix: touch and hold the OpenSRM icon → Remove App →
**Remove Bookmark**, then repeat Step 1 and Step 2.

## What to report back

1. iOS version (from Settings → General → About).
2. Did the permission prompt appear? (yes / no / already blocked)
3. Did the test notification appear? If yes: **how many seconds** after
   tapping the button, and did it show while the phone was locked?
4. One screenshot of the reminders card saying "Reminders on".
5. Anything odd you noticed.

The server also records a **delivery receipt** the moment the notification
reaches the phone, so if it never appears on screen we still know whether it
arrived — mention what you saw and we can compare.

> Note: this feature is marked **unverified** for iOS until this test passes.
> Android/desktop are already confirmed.
